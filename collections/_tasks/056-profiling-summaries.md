## Fit to programme

This task has been identified by the working groups as part of the agenda behind [WP 2.3](/workpackages/workpackage-2/).

The task number is 056.


## Summary

HPC systems are regularly used to deliver performance assessment workshops, and have many different performance, profiling and debugging tools installed as user accessible modules.  However, there is often no centralised location documenting these tools, and thus unfamiliar users and researchers may not know what is available and may not be able to determine what tools are suitable for their tasks.  This project will therefore create documentation for the platform website which describes the tools and gives detailed descriptions about how to use them, and how meaningful performance assessment, code debugging, and profiling can be carried out. This material will also be contributed back to the SHAREing website, contributing to a common set of coordinated guides on what tools are suitable for what purposes


## Methodology

Proposals for this project should deliver documentation on the platform website describing the available performance analysis, debugging and profiling tools that are available, how they can be used, and in which situations they are appropriate, and on the SHAREing website describing the same in non-site-specific terms.  Additionally, any tool gaps should be identified and where appropriate additional tools installed, in collaboration with system support staff.  Documentation should also point to relevant training materials for each tool.

## Outcomes

The key outputs will be documentation placed on the platform and SHAREing websites detailing the available profiling, debugging and analysis tools.  Additionally, installation of any tools required to fill gaps in capability should be carried out.  The key deliverable will by up to date webpages describing these tools.
